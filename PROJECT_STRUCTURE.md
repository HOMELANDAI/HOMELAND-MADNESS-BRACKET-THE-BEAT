# HomelandAI Madness: Bracket the Beat - Project Structure

This repository turns the complete HomelandAI Madness concept into a normal GitHub-ready project with product documentation, Supabase backend scaffolding, frontend UI concepts, operational playbooks, data-capture specs, and creative prompts.

## What This Project Is

**HomelandAI Madness: Bracket the Beat** is a music tournament, live event, remote voting game, prediction pool, data show, and premium content franchise by HAI. Beats or songs are selected, seeded, debated, previewed, voted on, and advanced through a bracket.

The strongest version combines:

- In-person event energy
- Phone-based private voting
- Remote gameplay through mini preview players
- Selection Sunday reveal drama
- Committee accountability
- Legend Vote reveals
- Blind Preview Mode
- Aftershow data analysis
- Twitch hype
- Maestro.tv premium interactivity

## Main Repo Areas

- `docs/` - product bible, game design, platform analysis, aftershow strategy, data mechanics, committee rules, prize structure, roadmap, and risk notes.
- `src/` - Next.js-style frontend scaffold with page and component examples.
- `supabase/` - Supabase schema, seed data, and Edge Function scaffolds.
- `templates/` - beat upload and tournament planning templates.
- `prompts/` - Google Studio Gemini, Figma, signage, NFT, and promo prompts.
- `admin/` - operator notes for tournament management.
- `beat-upload-patch/` - patch module for uploading and modifying tournament beat sets.

## Core Product Systems
